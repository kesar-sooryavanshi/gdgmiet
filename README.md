# 🚀 HackHeist 2026 — Landing Page

> An official single-page event landing website for **HackHeist**, organized by **GDG on Campus MIET**. Built strictly with clean, semantic, humanized **HTML5, CSS3, and Vanilla JavaScript**.

---

## 🌟 Overview & Highlights

HackHeist is a developer-focused gathering organized by GDG on Campus MIET where students learn, build, collaborate, and connect through workshops, speaker sessions, and a flagship hackathon.

### Exactly 5 Structured Sections
1. **Hero Section (`#hero`)**:
   - Main title: **HACKHEIST**
   - Tagline: **Build. Break. Solve.**
   - Organizer Badge: **GDG on Campus MIET**
   - Event Date: **HackHeist 2026**
   - Venue: **MIET, Meerut**
   - **Register Now** call-to-action button
2. **About HackHeist (`#about`)**:
   - Engaging explanation of the event's vision and developer mission.
   - 4 key impact metrics: 24+ Hours of Hacking, 300+ Builders, ₹50K+ Prizes, 100% Free Registration.
3. **Event Highlights (`#highlights`)**:
   - 💻 **Hackathon**: Build and showcase your ideas with real-world problem statements and live mentorship checkpoints.
   - 🛠️ **Workshop**: Learn practical development skills with hands-on coding, cloud workflows, and modern tools.
   - 🎤 **Tech Session**: Learn from experienced developers and Google Developer Experts with industry insights.
   - 🤝 **Networking**: Connect with students, seniors, and the broader developer community.
4. **Event Details (`#details`)**:
   - Real-time live countdown timer (Days, Hours, Minutes, Seconds) to HackHeist 2026.
   - Creative info cards: **Date (HackHeist 2026)**, **Venue (MIET)**, and **Time (9:00 AM onwards)**.
   - Venue directions card with direct Google Maps integration.
5. **Final CTA (`#register`)**:
   - Heading: **"Ready to HackHeist?"**
   - Interactive **Register Now** button triggering a modal registration form with instant validation and external Google Form fallback.

## 🎨 Design System & Aesthetics
- **Google / GDG Brand Palette**: Authentic, natural Google tones: Blue (`#1a73e8`), Red (`#d93025`), Amber (`#ea8600`), and Green (`#1e8e3e`).
- **Clean Human Aesthetic**: Natural crisp white card surfaces (`#ffffff`), soft slate backdrop (`#f8fafc`), clean subtle borders (`#e2e8f0`), high-contrast typography, and zero artificial neon glows.
- **Typography**: Google Fonts (*Inter* for readable body copy, *Plus Jakarta Sans* for crisp titles).
- **100% Responsive**: Tested across mobile (360px, 390px), tablets (768px), and desktops (1024px, 1366px, 1920px).

## 💻 How to Run Locally

### Option 1: Direct in Browser
Simply double-click `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python)
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

### Option 3: Local HTTP Server (Node.js)
```bash
npx serve .
```
